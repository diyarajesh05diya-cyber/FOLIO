## Pulse - Daily Briefing Bot

**Problem**  
Wanted a daily briefing without doing anything manually each morning.

**Approach**  
A Python bot with five functions pulling three free APIs, scheduled on GitHub Actions.

**Craft**  
Graceful try/except on every call, secrets handled the right way, downloadable artifact.

**Outcome**  
Runs autonomously at 8 AM IST, every day, for free. [Repo](https://github.com/diyarajesh05diya-cyber/FOLIO)
